# Тезис — документы и презентации из одной фразы

**Тезис** превращает короткую формулировку задачи в готовый файл Word, PDF или PowerPoint. Содержание собирает ИИ, структуру и вёрстку задаёт сайт, файл собирается прямо в браузере.

Сайт: **https://forma-docs.duckdns.org** · Зеркало: **https://ztrpgz.github.io/forma/**
Работает на компьютере и телефоне — без установки, регистрации и ключей доступа.

## Почему «Тезис»

| | У многих сервисов | В «Тезисе» |
| --- | --- | --- |
| Форматы | только слайды или только текст | Word, PDF и PowerPoint из одной темы |
| Файл | картинки, ссылки на редактор, водяные знаки | редактируемые DOCX и PPTX, готовый PDF |
| Слайды | «сколько получится», пункты-заглушки | обложка → содержание → финал, ровно 4–20 слайдов, фото с кадрированием |
| Доступ | регистрация, подписка, API-ключ | без аккаунта, установки и ключей |
| Шаблон | стандартные темы | 10 готовых тем, а свой .pptx — точь в точь со своим макетом |
| Данные | документ хранится в сервисе | шаблон разбирается в браузере, файл не загружается на сервер |

Скачанный файл — обычный документ Office: его можно править, отправлять и печатать. Предпросмотр на сайте повторяет вёрстку, но не заменяет файл.

## Как это работает

1. Выберите формат: **Word**, **PDF** или **PowerPoint**.
2. Смените оформление и число слайдов, если нужно, и введите тему — или оставьте поле пустым, и сайт подберёт пример.
3. Раскройте **«Критерии генерации»**, если нужен другой тон, читатель, фокус или детализация: можно добавить короткое пожелание к содержанию.
4. Нажмите **«Сгенерировать»** (или `Ctrl + Enter`).
5. Следите за этапами: **содержание → вёрстка → файл**.
6. Проверьте предпросмотр и скачайте файл кнопкой **«Скачать»**.
7. Нужны правки — нажмите **«Редактировать»**: измените заголовки и текст, добавьте фотографию для слайдов, затем нажмите **«Применить и обновить файл»**.

Выбранный формат, тема оформления, число слайдов и критерии запоминаются в браузере до следующего визита. Под полем темы есть готовые примеры для быстрого старта.

## Что можно создать

- **Word (DOCX)** — деловой документ на 4–6 разделов: титульная страница, заголовки, колонтитулы с номерами страниц, таблицы.
- **PDF** — аналитическая записка A4 с выводами, рекомендациями, таблицами и нумерацией страниц.
- **PowerPoint (PPTX)** — презентация по сюжету: **обложка с темой → содержательные слайды → финальный слайд с темой**. Число слайдов выбирается заранее: **4, 6, 8, 10, 12, 16 или 20** вместе с обложкой и финалом. На обычном шаблоне слайд 16:9: заголовок, вводный абзац, 4–5 конкретных пунктов и рамка под фото справа. На фирменном шаблоне **«МФЮА»** и на прикреплённом своём .pptx текст встаёт в плейсхолдеры исходного файла — фон, макеты, шрифты и размер слайда остаются нетронутыми.

После генерации документ можно править прямо на сайте: заголовок, подзаголовок и содержание разделов, а для презентации на обычном шаблоне — добавить одну фотографию на все содержательные слайды и настроить её масштаб и положение. Новый файл собирается в браузере по кнопке «Применить».

## Оформление

Десять встроенных шаблонов: **«Бумага»** (кремовый лист и медный акцент), **«Графит»** (холодный синий), **«Лес»** (глубокий зелёный), **«Терракота»** (тёплый кирпич), **«МФЮА»** (фирменный файл: фон, макеты и шрифты исходной презентации), **«Полночь»** (тёмный синий и золото), **«Океан»** (бирюза), **«Лаванда»** (фиолетовый), **«Кофе»** (эспрессо) и **«Сигнал»** (алый акцент). Цвета и шрифты применяются и в предпросмотре, и в скачанном файле.

Можно прикрепить свой **.docx или .pptx**. Для PowerPoint прикреплённый файл становится основой: сайт сохраняет его фон, мастер-слайд, макеты, тему и медиа, а из слайдов убирает старое содержание и подставляет в плейсхолдеры сгенерированный текст. Дизайн не перерисовывается. Для Word и PDF из файла берутся основные цвета и шрифты темы (нужен файл Office с темой `theme1.xml`), а вёрстка остаётся нашей. Файл разбирается прямо в браузере и никуда не загружается.

## Текст и данные

- Содержание собирает **ИИ-модель**: конкретные действия, роли, сроки, критерии и риски — без вводных фраз и канцелярита.
- Модель не придумывает числа, даты, проценты и исследования. Где точных данных нет, остаётся качественная формулировка, а заглушка «___» означает, что значение нужно вписать вручную.
- Для Word — деловой тон и план, для PDF — аналитика и рекомендации, для PowerPoint — подробный текст на слайдах: вводный абзац 180–240 знаков и 4–5 пунктов по 10–18 слов.
- **Критерии генерации** меняют подачу текста: тон (деловой, нейтральный, дружелюбный, убедительный), читатель (руководитель, команда, клиент, партнёр, студент), фокус (практика, стратегия, анализ, обзор) и детализация (кратко, стандарт, подробно). Отдельное пожелание до 200 знаков учитывается, если не противоречит структуре документа. На оформление критерии не влияют.
- Если ИИ недоступен, показывается демонстрационный документ с причиной и кнопкой **«Попробовать снова»**.

**Приватность.** Ключ доступа к ИИ хранится только на сервере и никогда не попадает в страницу или файл. Тема отправляется только для генерации текста; шаблон и готовые документы остаются в браузере. Регистрация и личные данные не нужны.

## Ограничения

- Предпросмотр приблизительный: системные шрифты и разбивка на страницы могут отличаться от скачанного файла. Для точного шаблона PowerPoint предпросмотр показывает только цвета и шрифты, а не фоны исходного файла.
- Точный шаблон PowerPoint заменяет только содержание слайдов: старые тексты, заметки и лишние слайды удаляются, а фото в такие презентации добавить нельзя — текст идёт в плейсхолдеры макета.
- Свой .docx и точный .pptx нужно прикреплять заново после перезагрузки страницы: файл не сохраняется в браузере.
- Редактор работает с текущим результатом: новая генерация начинает документ заново. Фотография доступна в PowerPoint; в Word и PDF редактируется только текст.
- Качество текста зависит от темы и модели. Демо-документ шаблонный — он нужен для проверки вёрстки.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| В метках «демо-режим», текст шаблонный | ИИ временно недоступен — нажмите «Попробовать снова» через минуту |
| «ИИ не ответил вовремя» | Повторите генерацию; для 16–20 слайдов ответ занимает 20–40 секунд |
| «ИИ вернул меньше разделов» | Модель не успела собрать план — нажмите «Попробовать снова» |
| «ИИ просит подождать» | Сработал лимит запросов или закончилась квота — подождите минуту |
| Предпросмотр пустой | Обновите страницу сочетанием `Ctrl + F5` |
| Шаблон не принят | Нужен `.docx` или `.pptx` с темой Office; другие файлы и архивы не подходят |
| На зеркале старая версия | Это кеш — подождите пару минут и обновите страницу |

## Технические детали

Браузеры: Chrome, Edge, Яндекс Браузер, Opera, Firefox и Safari 16.4+ — на компьютере и телефоне. Свой шаблон Office требует поддержки `DecompressionStream` (есть во всех актуальных версиях).

Всё работает без внешних CDN, библиотеки лежат на сайте: [docx](https://github.com/dolanmiu/docx), [PptxGenJS](https://github.com/gitbrent/PptxGenJS), [pdfmake](http://pdfmake.org/) — MIT; шрифт Roboto — Apache License 2.0. Georgia, Segoe UI, Franklin Gothic и другие шрифты тем в DOCX/PPTX не встраиваются: файлы используют системные шрифты, как обычные документы Office.
