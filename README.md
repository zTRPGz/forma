# FORMA — документы из одной фразы

Сайт: выбираете Word, PDF или PowerPoint, вводите тему — ИИ собирает содержание, а браузер верстает и скачивает готовый файл. Вёрстка и сборка файла происходят на странице; за ИИ отвечает маленькая серверная функция.

Работает без установки: `https://forma-docs.duckdns.org` или `https://ztrpgz.github.io/forma/`.

## Что умеет

- **Word (DOCX)** — титульная страница, стили заголовков и текста, колонтитулы с номерами страниц, таблицы.
- **PDF** — аналитическая записка A4: акцентные линейки, таблицы, нумерация страниц.
- **PowerPoint (PPTX)** — обложка и контентные слайды 16:9, таблицы, фирменный колонтитул. Кегль и высота строк таблицы подбираются автоматически, чтобы длинный текст не вылезал за слайд.
- **Предпросмотр на сайте**: PDF открывается во встроенном просмотрщике, Word показывается как страница A4, PowerPoint — как лента слайдов 16:9. Макет повторяет вёрстку файла, точные размеры — в скачанном документе.
- **Примеры тем** — четыре готовые подсказки под полем ввода: нажатие подставляет тему, ставит курсор в поле и заранее подгружает библиотеку выбранного формата.
- **Один текст — три формата**: содержание хранится отдельно от вёрстки.
- **Без настроек**: открыли ссылку на телефоне или компьютере, ввели тему — получили файл. Ни ключей, ни установки, ни батников.
- **Видно состояние ИИ**: при загрузке страница проверяет `/health`; в шапке написано «ИИ · на связи» или «ИИ · демо-режим». Если сервис не ответил, рядом с файлом появляется кнопка «Попробовать снова».
- **Понятный прогресс**: кнопка блокируется на время запроса, строка статуса пульсирует, а под заголовком результата появляются метки формата, модели и числа разделов.
- **Быстрая загрузка**: страница весит около 80 КБ; библиотеки DOCX/PDF/PPTX (0,5–2,2 МБ) подгружаются только под выбранный формат, при наведении на карточку или в момент генерации. На Vercel библиотеки кешируются на 30 дней, стили и скрипты — на 10 минут.

## Как пишется текст

Содержание собирает **GigaChat-2** по жёсткому редакционному заданию (`js/ai.js`):

- **Структура.** Заголовок до 10 слов, подзаголовок до 12 слов, 4–6 разделов с содержательными заголовками до 8 слов. Каждый раздел раскрывает свою мысль, без повторов.
- **Объём.** В разделе 1–3 абзаца по 400–700 знаков; абзац — 3–5 законченных предложений с конкретикой. Итоговый объём: Word — 1800–3000 знаков, PDF — 1500–2500, PowerPoint — 700–1200 (слайды не должны быть перегружены).
- **Польза.** Действия, сроки, ответственные, критерии и риски вместо общих рассуждений. Читатель — занятый руководитель.
- **Без вымысла.** Модели запрещено придумывать числа, даты, проценты, суммы, исследования и цитаты. Если в теме нет исходных цифр, запрос дополнительно требует качественных формулировок («сократит время подготовки отчётов»); заглушка «___» допустима только там, где без числа фраза теряет смысл.
- **Без разметки.** Только чистый текст: без markdown, звёздочек, решёток, эмодзи и подписей «Раздел 1».
- **Разный тон по формату.** Word — деловой документ с планом и ролями, PDF — аналитическая записка с выводами и рекомендациями, PowerPoint — короткие тезисы по 2–4 пункта на слайд.

### Проверка качества ответа

1. Ответ принимается только как JSON: markdown-обёртки срезаются, переносы строк и висячие запятые исправляются автоматически.
2. Если разобрать не удалось — запрос на исправление с черновиком, затем полная повторная генерация, затем ещё одно исправление.
3. Если документ получился пустым (меньше четырёх наполненных разделов или меньше 900 знаков для Word/PDF и 500 для PowerPoint) — модель просят расширить его, а короткий вариант отбрасывается.
4. Любой сбой (нет сети, таймаут, квота, невалидный JSON) не оставляет пользователя с пустым экраном: показывается демо-документ, причина и кнопка «Попробовать снова».

## Как это работает

```
браузер (https://ztrpgz.github.io/forma/ или https://forma-docs.duckdns.org)
   └─ POST /v1/chat/completions
        └─ Vercel Function (api/chat.js) → GigaChat API (OAuth, ключ в переменных окружения)
```

- Содержание пишет **GigaChat-2**. Функция сама получает OAuth-токен по `GIGACHAT_API_KEY`, поэтому сертификат Сбера и CORS браузеру не мешают, а ключ не попадает в страницу.
- Приложение просит ответ в JSON-режиме, при невалидном JSON делает запрос на исправление, при ошибке или таймауте (90 секунд) показывает демо-документ и причину сбоя.
- Сервер ограничивает себя по времени: 10 секунд на OAuth и 40 секунд на ответ модели, одно повторное соединение при обрыве сети, обновление токена при 401. Функция Vercel живёт максимум 60 секунд, поэтому браузер всегда получает понятный ответ, а не обрыв.
- Функция отвечает на `https://forma-docs.duckdns.org/v1/chat/completions`; для страницы на GitHub Pages это кросс-доменный запрос с разрешённым CORS. Если открыть сам адрес API, сайт работает и оттуда — запросы уходят на тот же домен.

## Быстрый старт

1. Откройте сайт: `https://forma-docs.duckdns.org` или `https://ztrpgz.github.io/forma/`.
2. Введите тему (или выберите пример) и нажмите «Сгенерировать» (`Ctrl + Enter`).
3. Проверьте структуру и предпросмотр, затем скачайте файл кнопкой «Скачать».

Локально: `python -m http.server 8000` в папке проекта, затем `http://127.0.0.1:8000` — страница обратится к серверной функции по её адресу в `js/ai.js`. Отдельный локальный сервер не нужен: ключ живёт только в переменных окружения Vercel.

## Публикация на GitHub Pages

Сайт опубликован из репозитория `zTRPGz/forma`: **Settings → Pages → Deploy from a branch → `main` / `(root)`**, адрес `https://ztrpgz.github.io/forma/`.

Чтобы повторить публикацию в другом репозитории:

1. Создайте **новый пустой репозиторий** на GitHub (без README и лицензии).
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "FORMA: документы из одной фразы"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
4. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Важно: загружайте **содержимое папки** (`index.html` должен лежать в корне репозитория), а не саму папку. Сборка, Node.js и внешние CDN не нужны: все библиотеки лежат в `vendor/`, пути относительные, `.nojekyll` уже добавлен.

Если сайт на Pages обновился не сразу, это кеш CDN GitHub: проверьте страницу с параметром `?v=дата` или подождите пару минут.

## Серверная часть (Vercel)

В папке `api/` лежат функции Vercel: `chat.js`, `models.js`, `health.js`. Адреса `/v1/chat/completions`, `/v1/models`, `/health` заданы перезаписями в `vercel.json`. Общая логика GigaChat — в `server/gigachat.cjs`. Ключ хранится только в переменной окружения `GIGACHAT_API_KEY` проекта Vercel (`GIGACHAT_SCOPE` — необязательно, по умолчанию `GIGACHAT_API_PERS`). В репозитории ключа нет.

Развёртывание (нужен аккаунт Vercel и CLI):

```bash
npx vercel login
npx vercel link                  # связать папку с проектом forma-ai
npx vercel env add GIGACHAT_API_KEY   # вставить Authorization key из developers.sber.ru
npx vercel deploy --prod
```

Проект: `forma-ai`, команда `trpg4`, домен `forma-docs.duckdns.org`.

`vercel.json` собирает `dist/` скриптом `tools/build-static.cjs` (только `index.html`, `styles.css`, `js/`, `vendor/`, `.nojekyll`). Статика раздаётся из `dist/`, поэтому служебные папки и ключи в публикацию не попадают; `.vercelignore` дополнительно исключает их из загрузки. Там же заданы заголовки кеширования (`/vendor/` — 30 дней, `/js/` и `styles.css` — 10 минут со stale-while-revalidate, `index.html` — без кеша) и защитные заголовки `X-Content-Type-Options` и `Referrer-Policy`.

Ссылки на CSS и JS в `index.html` версионируются (`?v=20261030`). При изменении скриптов или стилей поднимите версию: HTML не кешируется, поэтому браузер сразу запросит новые файлы, а старые версии останутся в кеше нетронутыми.

Бесплатный адрес `*.vercel.app` у некоторых провайдеров (в том числе МегаФон) не открывается. Поэтому к проекту подключён собственный домен `forma-docs.duckdns.org`: в DuckDNS запись `A → 216.198.79.1`, в Vercel — домен проекта. Сертификат Vercel выпускает сам; после этого работают и сайт, и API с любого устройства.

## Проверка после обновления

```bash
node tools/build-static.cjs                 # собрать dist/
npx vercel deploy --prod --scope trpg4      # опубликовать API и статику
```

1. `/health` возвращает `{"ok":true,"model":"GigaChat-2"}` — ключ на сервере есть, модель отвечает.
2. Шапка сайта показывает «ИИ · на связи», а не «демо-режим».
3. По одному документу каждого формата: файл скачивается, открывается, таблицы и колонтитулы на месте.
4. Заголовки кеша: `cache-control` у `/vendor/*` — `max-age=2592000`, у `index.html` — `max-age=0, must-revalidate`.
5. GitHub Pages: `index.html` и `js/ai.js` отдаются с новым содержимым, служебные пути (`/proxy/`, `/server/`) — 404.

## Структура

```
index.html            интерфейс: форматы, тема, результат
styles.css            оформление интерфейса
js/deps.js            ленивая загрузка библиотек под выбранный формат
js/model.js           модель документа, ограничения, нормализация, демо-текст
js/ai.js              промпт, запрос к серверной функции, JSON-схема, проверка качества, фолбэк
js/renderers.js       сборка DOCX, PPTX и PDF из одной модели
js/preview.js         HTML-макет Word (A4) и PowerPoint (16:9) без библиотек
js/app.js             состояние страницы и скачивание файлов
server/gigachat.cjs   OAuth и запросы к GigaChat, CORS, нормализация payload
api/                  chat, models, health — функции Vercel
vercel.json           заголовки, перезаписи /v1/chat/completions, /health и сборка dist/
tools/build-static.cjs   сборка dist/ из статики
vendor/               docx.js, PptxGenJS, pdfmake и шрифт Roboto
.nojekyll             отключает обработку Jekyll на GitHub Pages
```

Поток данных: `тема → ai.js → GigaChat → model.normalize → renderers[format] → Blob → скачивание`.

## Оформление

Интерфейс — тёплая бумажная палитра, крупная типографика и один акцентный цвет. Ключевые элементы:

- карточки форматов с иконкой, названием и примерами применения; выбранная карточка помечается точкой и акцентной рамкой;
- примеры тем под заголовком — компактные чипы, которые подставляют текст в поле;
- главная кнопка с подписью формата и стрелкой, которая сдвигается при наведении;
- карточка результата: метки «формат · модель · разделов», нумерованная структура с кружками и кнопка скачивания с иконкой;
- состояние ИИ в шапке: зелёная точка «на связи» или янтарная «демо-режим»;
- анимации отключаются при `prefers-reduced-motion`.

Палитра и шрифты документов заданы в `js/renderers.js` (константы `INK`, `NAVY`, `ACCENT`, `MUTED`, `RULE`, `HEAD_FONT`, `BODY_FONT`), интерфейса — CSS-переменные в начале `styles.css`. Чтобы изменить вид:

- **DOCX** — правьте стили `Forma Title`, `Forma Heading`, `Forma Body` и таблицы в `docxStyles()`.
- **PPTX** — сетка, отступы и типографика в `renderPptx()`; таблицы — `pptxTablePlan()`.
- **PDF** — стили и цвета в `renderPdf()`.
- **Интерфейс** — CSS-переменные в начале `styles.css`.

Ограничения на длину заголовков, абзацев, пунктов и таблиц находятся в `LIMITS` в `js/model.js` — они защищают вёрстку от переполнения.

## Ограничения

- Предпросмотр DOCX и PPTX — приблизительный HTML-макет: шрифты Georgia и Segoe UI заменяются системными, разбивка на страницы оценочная. Точная вёрстка — в скачанном файле.
- Качество текста зависит от модели и темы. Демо-текст — шаблонный, он нужен только для проверки вёрстки.
- Заглушка «___» в документе означает, что точных данных не было: впишите значение вручную.
- Нет истории документов и редактора после генерации: каждое нажатие «Сгенерировать» создаёт новый файл.
- У серверной функции нет пароля: кто знает адрес, может отправлять запросы. Квота ограничена вашим ключом GigaChat.
- Встроенный просмотр PDF на мобильных браузерах может быть ограничен — файл всегда можно скачать.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Шапка показывает «демо-режим» | `https://forma-docs.duckdns.org/health` — если `ok:false`, проверьте `GIGACHAT_API_KEY` в настройках проекта Vercel и квоту GigaChat |
| Файл скачивается, но текст шаблонный | Это демо-документ: в карточке результата есть причина и кнопка «Попробовать снова» |
| «ИИ не ответил вовремя» | Повторите запрос: сервер уже делает одно повторное соединение, иногда GigaChat отвечает дольше 40 секунд |
| Предпросмотр пустой | Обновите страницу с `Ctrl + F5`: библиотеки могли не догрузиться из-за сети |
| На GitHub Pages старая версия | Кеш CDN: откройте с `?v=2` или подождите пару минут |
