# FORMA — документы и презентации из одной фразы

Опишите тему — сайт соберёт содержание и сразу скачает готовый файл Word, PDF или PowerPoint. Тему можно не вводить: сайт подставит один из готовых примеров.

Сайт: **https://forma-docs.duckdns.org** (зеркало: https://ztrpgz.github.io/forma/). Работает в браузере на компьютере и телефоне — без установки, регистрации и ключей.

## Как пользоваться

1. Выберите формат: **Word**, **PDF** или **PowerPoint**.
2. При желании выберите оформление и число слайдов (для презентации), введите тему или оставьте поле пустым.
3. Нажмите **«Сгенерировать»** (или `Ctrl + Enter`). Проверьте предпросмотр и скачайте файл кнопкой **«Скачать»**.

Формат, выбранное оформление и число слайдов запоминаются в браузере до следующего визита.

## Что можно создать

- **Word (DOCX)** — деловой документ на 4–6 разделов: титульная страница, заголовки, колонтитулы с номерами страниц, таблицы.
- **PDF** — аналитическая записка A4 с выводами и рекомендациями, таблицами и нумерацией страниц.
- **PowerPoint (PPTX)** — презентация 16:9. Число слайдов выбирается заранее: **4, 6, 8, 10, 12, 16 или 20** вместе с титульным. Сколько выбрали — столько слайдов и будет: один раздел на слайд, 2–4 коротких пункта, без перегруза текстом.

Предпросмотр на сайте повторяет вёрстку файла: Word и PDF — страницы A4, PowerPoint — лента слайдов 16:9. Это облегчённый макет, поэтому точные размеры и разбивка на страницы — в скачанном файле.

## Оформление

Четыре встроенных шаблона: **«Формовка»** (тёплая бумага), **«Графит»**, **«Лес»**, **«Терракота»**. Цвета и шрифты применяются и в предпросмотре, и в скачанном файле.

Можно прикрепить свой **.docx или .pptx** — сайт возьмёт из него основные цвета и шрифты темы. Готовая вёрстка, фоны и колонтитулы исходного файла не переносятся. Файл разбирается прямо в браузере и никуда не загружается.

## Текст и данные

- Содержание пишет **GigaChat-2**. Текст конкретный: действия, роли, сроки, критерии и риски — без вводных фраз и канцелярита.
- Модель не придумывает числа, даты, проценты и исследования. Если точных данных нет, формулировка остаётся качественной, а заглушка «___» означает, что значение нужно вписать вручную.
- Для Word — деловой тон и план, для PDF — аналитика и рекомендации, для PowerPoint — короткие тезисы.
- Если ИИ недоступен, показывается демонстрационный документ с причиной и кнопкой «Попробовать снова» — сайт не оставляет пустой экран.

**Приватность.** Ключ доступа к ИИ хранится только на сервере и никогда не попадает в страницу или файл. Регистрация, личные данные и настройки не нужны. Ваша тема отправляется только для генерации текста; шаблон и документы остаются в браузере.

## Ограничения

- Предпросмотр приблизительный: системные шрифты и разбивка на страницы могут отличаться от скачанного файла.
- Свой шаблон даёт только цвета и шрифты, а не макет. Нужен файл Office с темой (`theme1.xml`), иначе появится понятная ошибка.
- Нет истории и редактирования после генерации: каждое нажатие «Сгенерировать» создаёт новый файл.
- Качество текста зависит от темы и модели. Демо-документ — шаблонный, он нужен для проверки вёрстки.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| В метках написано «демо-режим», текст шаблонный | ИИ временно недоступен — нажмите «Попробовать снова» через минуту |
| «ИИ не ответил вовремя» | Повторите генерацию; для 16–20 слайдов ответ занимает 20–30 секунд |
| Предпросмотр пустой | Обновите страницу сочетанием `Ctrl + F5` |
| Шаблон не принят | Нужен `.docx` или `.pptx` с темой Office; другие файлы и архивы не подходят |
| На зеркале GitHub Pages старая версия | Это кеш — подождите пару минут и обновите страницу |

## Браузеры

Chrome, Edge, Яндекс Браузер, Opera, Firefox и Safari 16.4+ — на компьютере и телефоне. Свой шаблон Office требует современного браузера с поддержкой `DecompressionStream` (все актуальные версии перечисленных браузеров).

## Библиотеки

Всё работает без внешних CDN, библиотеки лежат на сайте:

- [docx](https://github.com/dolanmiu/docx) 9.15.0 — MIT;
- [PptxGenJS](https://github.com/gitbrent/PptxGenJS) 4.0.1 — MIT;
- [pdfmake](http://pdfmake.org/) 0.2.20 — MIT;
- Roboto — Apache License 2.0.

Georgia и Segoe UI в DOCX/PPTX не встраиваются: файлы используют системные шрифты, как обычные документы Office.
