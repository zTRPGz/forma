# FORMA — документы из одной фразы

Статический сайт: выбираете Word, PDF или PowerPoint, вводите тему — ИИ собирает содержание, а браузер верстает и скачивает готовый файл. Сервер, сборка и установка зависимостей не нужны: всё исполняется на странице, файлы создаются локально.

## Что умеет

- **Word (DOCX)** — титульная страница, стили заголовков и текста, колонтитулы с номерами страниц, таблицы.
- **PDF** — аналитическая записка A4: акцентные линейки, таблицы, нумерация страниц.
- **PowerPoint (PPTX)** — обложка и контентные слайды 16:9, таблицы, фирменный колонтитул. Кегль и высота строк таблицы подбираются автоматически, чтобы длинный текст не вылезал за слайд.
- **Один текст — три формата**: содержание хранится отдельно от вёрстки.
- **Демо-режим** без ключа: сайт сразу показывает, как выглядит результат.
- **Свой ИИ**: любой OpenAI-совместимый endpoint, по умолчанию `gpt-4o-mini` — та же модель, что в конфигурации DocMate.
- **Ключ не в репозитории**: он вводится в интерфейсе и хранится только в `localStorage` браузера.
- **Быстрая загрузка**: страница весит около 80 КБ; библиотеки DOCX/PDF/PPTX (0,5–2,2 МБ) подгружаются только под выбранный формат, при наведении на карточку или в момент генерации.

## Быстрый старт

1. Откройте `index.html` в браузере. Для демо-режима больше ничего не нужно.
2. Введите тему и нажмите «Сгенерировать» (или `Ctrl + Enter`).
3. Файл скачается кнопкой «Скачать».

Если браузер ограничивает запросы к API со страницы `file://`, запустите локальный сервер:

```bash
python -m http.server 8000
```

и откройте `http://127.0.0.1:8000`.

## Публикация на GitHub Pages

1. Создайте **новый пустой репозиторий** на GitHub (без README и лицензии).
2. В папке проекта выполните:

```bash
git init
git add .
git commit -m "FORMA: документы из одной фразы"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.
4. Через минуту сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Важно: загружайте **содержимое папки** (`index.html` должен лежать в корне репозитория), а не саму папку. Сборка, Node.js и внешние CDN не нужны: все библиотеки лежат в `vendor/`, пути относительные, `.nojekyll` уже добавлен.

Если на компьютере уже есть git-репозиторий уровнем выше (например, в домашней папке), создавайте новый репозиторий именно в папке проекта — команды выше это и делают.

## Подключение ИИ

1. Нажмите «Настройки».
2. Адрес API: `https://api.openai.com/v1`.
3. Модель: `gpt-4o-mini`.
4. Вставьте API-ключ и нажмите «Сохранить». Кнопка «Показать» помогает проверить вставку.

Ключ хранится в `localStorage` этого браузера и отправляется напрямую в выбранный API. В коде и репозитории ключа нет. Не вписывайте ключ в файлы и не публикуйте его. Для публичного сайта разумно использовать отдельный ключ с ограниченной квотой.

Подойдёт любой OpenAI-совместимый endpoint с методом `/chat/completions`, который возвращает JSON. Приложение:

- просит ответ в JSON-режиме, а если провайдер его не поддерживает — повторяет запрос без `response_format`;
- убирает `max_tokens`, если модель требует `max_completion_tokens`;
- при невалидном JSON делает один запрос на исправление;
- понимает ответ, где `content` пришёл строкой или массивом частей;
- при ошибке, таймауте (90 секунд) или отсутствии ключа показывает демо-документ и причину сбоя.

Если `api.openai.com` отвечает `403 Country, region, or territory not supported`, доступ из вашей сети закрыт. Укажите в поле «Адрес API» прокси или другой OpenAI-совместимый сервис — приложение не привязано к OpenAI, достаточно поменять адрес и модель.

Адрес проверяется при сохранении: принимается только `http(s)://`, хвост `/chat/completions` отбрасывается автоматически. На https-сайте нельзя указать http-адрес (кроме localhost) — браузер заблокирует такой запрос, и приложение предупредит об этом заранее.

### Почему не GigaChat из DocMate

В DocMate GigaChat работает через OAuth с клиентским секретом и российскими корневыми сертификатами — это серверный сценарий. В статической странице секрет был бы виден любому посетителю, а браузерные CORS-запросы к OAuth-серверу не пройдут. Поэтому в статичной версии используется OpenAI-совместимый `gpt-4o-mini` из конфигурации DocMate; при необходимости адрес API можно заменить на свой прокси, в том числе к GigaChat.

## Структура

```
index.html            интерфейс: форматы, тема, настройки, результат
styles.css            оформление интерфейса
js/deps.js            ленивая загрузка библиотек под выбранный формат
js/model.js           модель документа, ограничения, нормализация, демо-текст
js/ai.js              запрос к LLM, JSON-схема, ключ в localStorage, фолбэк
js/renderers.js       сборка DOCX, PPTX и PDF из одной модели
js/app.js             состояние страницы и скачивание файлов
vendor/               docx.js, PptxGenJS, pdfmake и шрифт Roboto
.nojekyll             отключает обработку Jekyll на GitHub Pages
```

Поток данных: `тема → ai.js → model.normalize → renderers[format] → Blob → скачивание`.

## Оформление

Палитра и шрифты заданы в `js/renderers.js` (константы `INK`, `NAVY`, `ACCENT`, `MUTED`, `RULE`, `HEAD_FONT`, `BODY_FONT`) и в `styles.css` для интерфейса. Чтобы изменить вид:

- **DOCX** — правьте стили `Forma Title`, `Forma Heading`, `Forma Body` и таблицы в `docxStyles()`.
- **PPTX** — сетка, отступы и типографика в `renderPptx()`; таблицы — `pptxTablePlan()`.
- **PDF** — стили и цвета в `renderPdf()`.
- **Интерфейс** — CSS-переменные в начале `styles.css`.

Ограничения на длину заголовков, абзацев, пунктов и таблиц находятся в `LIMITS` в `js/model.js` — они защищают вёрстку от переполнения.

## Ограничения

- DOCX и PPTX не показываются в браузере: файл скачивается и открывается в Word или PowerPoint. PDF показывается во встроенном просмотрщике браузера.
- Качество текста зависит от модели и темы. Демо-текст — шаблонный, он нужен только для проверки вёрстки.
- Нет истории документов и редактора после генерации: каждое нажатие «Сгенерировать» создаёт новый файл.
- Ключ хранится в браузере, поэтому при очистке данных сайта его нужно ввести заново.
- Встроенный просмотр PDF на мобильных браузерах может быть ограничен — файл всегда можно скачать.
