# Тезис — документы и презентации из одной фразы

**Тезис** — сайт, который превращает короткую формулировку задачи в готовый файл Word, PDF или PowerPoint. Содержание собирает GigaChat, структуру и вёрстку задаёт сайт, файл создаётся прямо в браузере.

Сайт: **https://forma-docs.duckdns.org** (зеркало: https://ztrpgz.github.io/forma/). Работает на компьютере и телефоне — без установки, регистрации и ключей доступа.

## Как это работает

1. Выберите формат: **Word**, **PDF** или **PowerPoint**.
2. При желании смените оформление и число слайдов (для презентации), введите тему — или оставьте поле пустым, и сайт подберёт пример.
3. Нажмите **«Сгенерировать»** (или `Ctrl + Enter`).
4. Следите за этапами сборки: **содержание → вёрстка → файл**.
5. Проверьте предпросмотр и скачайте файл кнопкой **«Скачать»**.

Формат, оформление и число слайдов запоминаются в браузере до следующего визита. Под полем темы работают подсказки — готовые темы для быстрого старта.

## Что можно создать

- **Word (DOCX)** — деловой документ на 4–6 разделов: титульная страница, заголовки, колонтитулы с номерами страниц, таблицы.
- **PDF** — аналитическая записка A4 с выводами, рекомендациями, таблицами и нумерацией страниц.
- **PowerPoint (PPTX)** — презентация 16:9 по сюжету: **обложка с темой → содержательные слайды → финальный слайд с темой**. Число слайдов выбирается заранее: **4, 6, 8, 10, 12, 16 или 20** вместе с обложкой и финалом. На каждом содержательном слайде есть заголовок, вводный абзац, 4–5 конкретных пунктов и рамка под фото справа.

Предпросмотр повторяет вёрстку файла: Word и PDF — страницы A4, PowerPoint — лента слайдов 16:9. Это облегчённый макет, поэтому точные размеры и разбивка на страницы — в скачанном файле.

## Оформление

Четыре встроенных шаблона: **«Бумага»** (кремовый лист и медный акцент), **«Графит»**, **«Лес»**, **«Терракота»**. Цвета и шрифты применяются и в предпросмотре, и в скачанном файле.

Можно прикрепить свой **.docx или .pptx** — сайт возьмёт из него основные цвета и шрифты темы. Готовая вёрстка, фоны и колонтитулы исходного файла не переносятся: нужен файл Office с темой (`theme1.xml`). Файл разбирается прямо в браузере и никуда не загружается.

## Текст и данные

- Содержание пишет **GigaChat-2**. Текст конкретный: действия, роли, сроки, критерии и риски — без вводных фраз и канцелярита.
- Модель не придумывает числа, даты, проценты и исследования. Если точных данных нет, формулировка остаётся качественной, а заглушка «___» означает, что значение нужно вписать вручную.
- Для Word — деловой тон и план, для PDF — аналитика и рекомендации, для PowerPoint — подробный текст на слайдах: вводный абзац 180–240 знаков и 4–5 пунктов по 10–18 слов.
- Если ИИ недоступен, показывается демонстрационный документ с причиной и кнопкой **«Попробовать снова»** — сайт не оставляет пустой экран.

**Приватность.** Ключ доступа к ИИ хранится только на сервере и никогда не попадает в страницу или файл. Регистрация, личные данные и настройки не нужны. Ваша тема отправляется только для генерации текста; шаблон и готовые документы остаются в браузере.

## Оформление интерфейса

Сайт оформлен как рабочая папка с документами: кремовая бумага, глубокий синий, медный акцент. На обложке — композиция из листов Word, PDF и слайда с рамкой под фото. Аккуратные анимации показывают, как появляются строки документа, и не мешают работе: при системной настройке «уменьшить движение» они отключаются.

Во время генерации виден прогресс: этап **«Содержание»**, затем **«Вёрстка»** и **«Файл»**. После завершения блок складывается, а результат появляется с заголовком, структурой и метками формата, темы и времени сборки.

## Ограничения

- Предпросмотр приблизительный: системные шрифты и разбивка на страницы могут отличаться от скачанного файла.
- Свой шаблон даёт только цвета и шрифты, а не макет.
- Нет истории и редактирования после генерации: каждое нажатие «Сгенерировать» создаёт новый файл.
- Качество текста зависит от темы и модели. Демо-документ — шаблонный, он нужен для проверки вёрстки.

## Если что-то не работает

| Симптом | Что сделать |
| --- | --- |
| В метках написано «демо-режим», текст шаблонный | ИИ временно недоступен — нажмите «Попробовать снова» через минуту |
| «ИИ не ответил вовремя» | Повторите генерацию; для 16–20 слайдов ответ занимает 20–40 секунд |
| Показан демо-документ «ИИ вернул меньше разделов» | Модель не успела собрать весь план — нажмите «Попробовать снова»; для больших презентаций это иногда требует второй попытки |
| «ИИ просит подождать» | Сработал лимит запросов или закончилась квота — подождите минуту и повторите |
| Предпросмотр пустой | Обновите страницу сочетанием `Ctrl + F5` |
| Шаблон не принят | Нужен `.docx` или `.pptx` с темой Office; другие файлы и архивы не подходят |
| На зеркале GitHub Pages старая версия | Это кеш — подождите пару минут и обновите страницу |

## Браузеры

Chrome, Edge, Яндекс Браузер, Opera, Firefox и Safari 16.4+ — на компьютере и телефоне. Свой шаблон Office требует современного браузера с поддержкой `DecompressionStream` (все актуальные версии перечисленных браузеров).

## Библиотеки

Всё работает без внешних CDN, библиотеки лежат на сайте:

- [docx](https://github.com/dolanmiu/docx) — MIT;
- [PptxGenJS](https://github.com/gitbrent/PptxGenJS) — MIT;
- [pdfmake](http://pdfmake.org/) — MIT;
- Roboto — Apache License 2.0.

Georgia и Segoe UI в DOCX/PPTX не встраиваются: файлы используют системные шрифты, как обычные документы Office.
